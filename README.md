# Bernard's Arcade

TV arcade for **Bernard**, a long-haired German Shepherd.

Two games:

- **Flappy Bernard** — flap through the brick gaps, grab the tennis balls
- **Flying with Bernard** — biplane or firefighter jet, collect balls, shoot birds and enemy planes

Built to play in a browser on an Onn 4K Pro with a USB SNES pad.

## Controls (SNES)

| Button | Menu | In game |
| --- | --- | --- |
| D-pad | Choose | Move / flap |
| B or A | Play | Flap / shoot |
| Start | — | Pause |
| Select | — | Back |

Keyboard works too: arrows + Enter, Space to flap/shoot, Esc to go back.

## Play

This repo is the GitHub home for the project. The playable web app is published from Grok App Builder (Share / Publish in the project preview).
